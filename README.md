# Sustainability Assessment Concentration

An undergraduate engineering concentration at King Fahd University of Petroleum and Minerals (KFUPM): four courses on managing, measuring, reporting and reducing environmental impact.

## Contents

- `index.html`: animated page for prospective students (courses, what you will be able to do, credentials, career roles, video, flyers)
- `sustainability-assessment.mp4`: narrated overview video, with captions in `sustainability-assessment.vtt` and the text in `narration-script.txt`
- `flyers/`: one-page program flyer and one flyer per course (PDF)

## Publish with GitHub Pages

Settings > Pages > Source: Deploy from a branch > Branch: `main`, folder `/ (root)`.

## Courses

1. Environmental Management and Assessment
2. ARE 460 Green and Sustainable Buildings
3. Emissions Estimation and Reporting
4. Circularity and Life Cycle Assessment
